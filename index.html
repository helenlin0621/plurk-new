噗浪新噗篩選

在噗浪的話題排行榜（plurk.com/top）點一下書籤，只列出你還沒看過的熱門噗；回應、喜歡、轉噗三個榜可以切換或合併，每天固定開新噗的串可以設關鍵字隱藏。

安裝

把下面這個按鈕拖到 Chrome 的書籤列（書籤列沒顯示的話，按 Ctrl+Shift+B 打開）：

噗浪新噗

拖不過去的話：按「複製書籤網址」，在書籤列按右鍵 →「新增網頁」，名稱填「噗浪新噗」，網址貼上。舊版書籤要刪掉換成新的，才會有三個榜。

想收藏噗之後回顧的話，把這個也拖到書籤列：

收藏

其他小工具

一樣拖到書籤列就能用，任何網頁都可以點。只改目前這一頁的外觀，重新整理就恢復。

去背

拿掉頁面的背景圖片與背景色，並移除 bar-color 樣式。

去CSS

把整頁切成黑白（灰階）；再點一次恢復彩色。

使用

  1. 打開 https://www.plurk.com/top，點書籤列的「噗浪新噗」，右側會跳出清單。
  2. 上方可以切換「回應／喜歡／轉噗／全部」，括號是各榜還沒看過的則數。一開始會停在你目前看的那個分頁；「全部」是三個榜合併、去掉重複。
  3. 點清單裡的噗，會在新分頁打開，並記成「已看」；不想點開的，按右邊的「已看」也可以。已看紀錄三個榜共用，在一個榜看過，其他榜也不會再出現。
  4. 第一次用時全部都算新的，可以先切到「全部」按「全部標為已看」，之後就只會看到新上榜的噗。
  5. 按「關鍵字」設定要隱藏的固定串，一行一個，例如 台股閒聊噗、#直覺遊戲。噗文內容包含任一行就會隱藏（不分大小寫）。

收藏

  1. 看完一則噗覺得之後想回顧，點書籤列的「收藏」，右上角會出現「★ 已收藏」。再點一次就是取消收藏。
  2. 單則噗的頁面（網址是 plurk.com/p/…）點了就直接收藏這一則。從新噗清單點開的、別人貼的連結都是這種頁面。
  3. 在河道上（例如偷偷說河道）點的話：有點開一則噗就收藏那一則；判斷不出是哪一則時，會列出畫面上的噗讓你挑，按「☆收藏」。
  4. 回顧：在排行榜點「噗浪新噗」，切到「★收藏」分頁。點噗會在新分頁打開；不要了就按「取消收藏」。
  5. 收藏過的噗不會出現在新噗清單裡。

跨電腦同步（選用）

公司、家裡兩台電腦輪流用的話，可以把已看紀錄、收藏、關鍵字存到你自己 GitHub 帳號裡的一個私人 Gist，換台時按一下就帶過去。不設定也能照常使用。

  1. 先產生金鑰：登入 GitHub 後打開 github.com/settings/personal-access-tokens/new。
    • Token name 填 plurk-new，Expiration 選 1 年。
    • Permissions → Account permissions → Gists 選「Read and write」，其他都不動。
    • 按 Generate token，複製那串 github_pat_…。
  2. 在排行榜點「噗浪新噗」，按側欄最下面的「☁ 設定同步」，貼上金鑰，按「測試並儲存」。兩台電腦都要各設定一次，用同一組金鑰就可以。
  3. 要離開這台前按底部的「上傳」；到另一台後按「下載」。看到「上傳 •」表示這台有還沒上傳的新紀錄。
  • 上傳、下載都是合併，不會整份蓋掉；在一台取消收藏，另一台下載後也會取消。
  • 關鍵字以最後修改的那台為準。
  • 金鑰只存在這台電腦的噗浪網站資料裡，而且只能動 Gist，碰不到你的程式 repo。要換或停用，按底部的 ⚙。
  • 金鑰過期時上傳會失敗並提示，照第 1 步再產生一組貼上即可。

說明

  • 清單來自噗浪排行榜的 24 小時榜：最多人回應、最多人喜歡、最多人轉噗，每榜最多 90 則。
  • 每則顯示：在哪幾個榜、排第幾，總回應／喜歡／轉噗數，以及發文多久了。發文超過一天的會標「舊噗」，方便判斷是不是剛好第一次看到的老噗。
  • 「全部」依各榜中最好的名次排序，名次相同時，上越多榜的排前面。
  • 已看紀錄和關鍵字存在這台電腦、這個瀏覽器的噗浪網站資料裡，換電腦或清除網站資料就會重來（有設定同步的話，下載就能拿回來）。已看紀錄保留 60 天；收藏不會自動刪，要自己取消。
  • 只讀不寫：不會替你回噗、按喜歡或做任何操作。同步只會寫你自己 GitHub 的那一個 Gist。

解除安裝

  1. 在排行榜點「噗浪新噗」，按側欄最下面的「清除全部資料」，確認後會刪掉已看紀錄、收藏、關鍵字和同步金鑰（噗浪的登入不受影響）。有用同步的話，雲端的 Gist 不會刪，要刪請到 gist.github.com 自己刪。
  2. 在書籤列的「噗浪新噗」「收藏」上按右鍵 →「刪除」。

只刪書籤不會清掉資料，所以要先做第 1 步。
